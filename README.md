# パンダロイヤル大会マネージャー 🐼

30人規模のダイスゲーム大会の進行、参加者からのスコア収集、順位・順位点の自動集計、次ラウンドの座席自動抽選をリアルタイムに行うWebアプリケーションです。

---

## 🎯 主な特徴と機能

### 1. 📝 エントリー画面（参加者・スマホ対応）
- つなげーとIDと名前（ニックネーム）を入力するだけで、スマホから誰でも簡単にワンクリックでエントリー完了。
- 登録時は「一般参加者」として登録され、パスワード等の複雑な入力は一切不要です。

### 2. 🎲 スコア入力画面（参加者・スマホ対応）
- 各ラウンド（予選1 / 予選2 / 決勝）終了後、自分の名前を選択して獲得スコアを送信。
- 卓情報（A卓・B卓・C卓など）や座席番号はシステムが保持しているため、プレイヤーによる卓番号の誤入力を完全に防止します。
- 送信後、同じ卓の入力進捗や暫定順位がリアルタイムに確認できます。

### 3. 📊 ダッシュボード画面（閲覧専用・会場スクリーン/スマホ）
- **総合ランキング**: 順位点の合計を最優先とし、同点の場合は獲得スコアの合計でタイブレークした総合順位をリアルタイム表示。
- **座席表**: 各ラウンドの卓（A卓・B卓・C卓 / チャンピオン卓・シルバー卓・ブロンズ卓）ごとの座席配置をカード形式でわかりやすく表示。

### 4. ⚙️ 管理者ページ（運営者専用・PC/タブレット）
- 管理者パスワード認証で保護された管理画面。
- **参加者一覧・タグ付け機能**: 登録された参加者一覧を確認しながら、「一般」「運営」の属性をテーブル上で直接選択・一括保存可能。ワンクリックでの個別切り替えにも対応。
- **予選1・2の座席自動抽選**: タグ付けされた運営メンバーをA/B/C卓に均等（各卓1〜2名）に振り分け、残りの枠に一般メンバーをシャッフル配分。
- **決勝ラウンドの座席自動抽選と運営足切り処理**:
  - 予選総合順位に基づき、1〜10位を「チャンピオン卓」、11〜20位を「シルバー卓」、21〜30位を「ブロンズ卓」に仮配置。
  - チャンピオン卓内の運営メンバーが上限（設定可能・デフォルト3名）を超える場合、順位の低い運営を自動降格させ、シルバー卓の最上位一般メンバーを自動昇格。
- **参加者手動追加・誤登録削除**: 管理者が代理で参加者を追加したり、誤った登録を削除可能。
- **リハーサル用テスト機能**: 30名の一括ダミー登録および予選スコアの自動シミュレーション機能を搭載。

## 🚀 起動方法

### 簡単起動（Windows環境）
フォルダ内にあるバッチファイルをダブルクリックするだけで自動的に準備と起動が行われます。

1. **初回起動時**: `setup_and_run.bat` をダブルクリック
   - 仮想環境の作成、必要ライブラリの自動インストール、アプリの起動が自動で行われます。
2. **2回目以降の起動**: `run.bat` をダブルクリック
   - ブラウザが自動的に立ち上がり、アプリ画面が表示されます。

ブラウザのURL: `http://localhost:8501`

## ⚙️ 環境変数設定 (.env)

必要に応じて `.env` ファイル内の設定を変更できます。

```env
ADMIN_PASSWORD=panda2026
```
- `ADMIN_PASSWORD`: 運営スタッフの登録時および運営管理画面へのログイン時に使用するパスワードです。
