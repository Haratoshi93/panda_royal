# パンダロイヤル大会マネージャー 🐼

30人規模のダイスゲーム大会の進行、参加者からのスコア収集、順位・順位点の自動集計、次ラウンドの座席自動抽選をリアルタイムに行うスマートフォン最適化Webアプリケーションです。

---

## 🎯 主な特徴と機能

### 📱 シンプルな4画面構成（参加者・運営共通ナビゲーション）
画面上部の4つのタブを切り替えて利用します。

1. **🏠 ホーム**: 運営が切り替えた現在の大会フェーズに完全連動して画面が自動変化します。
2. **📊 順位**: エントリー〜決勝戦までは暫定総合ランキング（チャンピオン卓進出ライン表示付き）を確認でき、結果発表フェーズでは決勝テーブル別の結果と全ラウンド総合ランキングを確認できます。
3. **🪑 座席**: 現在の大会進行に応じたラウンドの座席表を自動選択し、全卓（A卓・B卓・C卓、決勝はチャンピオン卓・シルバー卓・ブロンズ卓）を縦並び一覧で表示します。各卓の最上位（1番席〜）には運営スタッフが配置・表示されます。
4. **⚙️ 管理**: パスワード認証で保護された運営管理コンソールです。

---

### 🚩 大会進行フェーズ連動システム（8つのステップ）
運営が「⚙️ 管理」画面でフェーズを切り替えることで、参加者の「🏠 ホーム」画面が現在の進行状況に合わせて自動的に切り替わります。

1. **エントリーフェーズ**:
   - 参加者の受付登録。スマホからつなげーとIDとニックネームだけで簡単エントリー。
   - **定員30名自動締め切りロック**: 登録数が上限の30名に達すると、新規エントリーフォームが自動的に締め切り表示に切り替わり、31人目以降の誤登録を防ぎます。
   - 登録時に自分の名前をブラウザセッションに記憶するため、以降の座席確認やスコア送信で何度も名前を探し直す手間が省けます。
2. **予選１　準備（席替え表示）**:
   - 予選1の座席発表と席替え案内。自分の名前を選ぶと座席チケットバナーが大きく表示され、スムーズに着席できます（一度選ぶと次のラウンドでも自動記憶されます）。
3. **予選１　結果入力**:
   - 予選1終了後のスコア報告。自分の獲得スコアを送信でき、同じテーブルのメンバーの入力状況もリアルタイムで確認できます。
4. **予選２　準備（席替え表示）**:
   - 予選2の席替え案内。予選1と同じ相手との再同卓を最小化した座席表と暫定順位を確認できます。
5. **予選２　結果入力**:
   - 予選2終了後のスコア報告。
6. **決勝戦　準備（席替え表示）**:
   - 予選総合順位と運営足切り処理に基づく決勝進出卓の発表。チャンピオン卓・シルバー卓・ブロンズ卓の進出先と座席番号を案内。
7. **決勝戦　結果入力**:
   - 決勝戦終了後のスコア報告。
8. **結果発表（最終スコア表示）**:
   - 表彰式！チャンピオン卓の上位入賞者カードと、全ラウンドを通じた最終総合ランキングが公開されます。

---

### ⚙️ 管理画面（運営管理コンソール）の主な機能
- **大会フェーズ進行（「次へ進める ➔」「⬅️ 戻す」ボタン）**:
  - 誤操作を防ぐシンプルな前後移動ボタン式。
  - 未抽選のラウンドやスコア未入力者が残っている場合は、進行ボタン直下に「事前確認のお知らせ」が表示されるため、状況を確認しながら安心して進行できます。
- **👥 タグ付け**:
  - ワンタップで参加者の「運営」「一般」属性を切り替え可能。手動の代理登録や参加者削除（関連スコア順位の自動再計算付き）も行えます。
- **🎯 座席抽選（多層セーフティ付き）**:
  - **運営3名以上・定員30名以下セーフティ**: 全3卓に運営スタッフを最低1名配置するため、運営タグが3名未満の場合や定員30名超過時は安全ロックがかかります。
  - **順番制御セーフティ**: 予選1未抽選時の予選2抽選や、予選未完了時の決勝抽選を自動でブロックします。
  - **予選2 同卓重複最小化アルゴリズム**: 予選1で同じ卓だったプレイヤー同士が予選2で固まらないよう自動で均等分散します。
  - **決勝 運営足切り・繰り上げ昇格**: チャンピオン卓の運営上限人数（デフォルト3名）を超えた場合、下位の運営スタッフをシルバー卓へ降格し、シルバー卓上位の一般参加者を自動昇格させます。
- **📊 入力進捗 & スコア代理入力・修正**:
  - 各ラウンドの入力率と未入力者名をリアルタイムで確認できます。
  - **スコアの代理入力・修正機能**: 参加者のスマホ電池切れや誤入力があった場合でも、全体の進行フェーズを前に戻すことなく、運営側からどのラウンド・どのプレイヤーのスコアでも直接入力・修正・未入力戻しを行えます。
- **📱 QR・URL**:
  - 会場案内用のQRコード表示とPNG画像ダウンロード、公開アクセスURLの変更ができます。
- **🛠️ 管理/DB**:
  - SQLiteデータベース（`.db`）のワンクリックバックアップ保存と復元、リハーサル用ダミーデータ生成・スコア生成、全データ初期化を実行できます。

## 🚀 起動方法と運用環境

### 本番環境（Streamlit Community Cloud）
- Webブラウザやスマホから直接アクセスして運用できます。
- スリープ防止のため、GitHub Actions（`.github/workflows/keep_awake.yml`）による定期アクセスが設定されています。

### ローカル環境（Windows）
フォルダ内のバッチファイルをダブルクリックして起動できます。

1. **初回起動時**: `setup_and_run.bat` をダブルクリック
   - 仮想環境（`.venv`）の作成、必要ライブラリのインストール、アプリの起動が自動で行われます。
2. **2回目以降の起動**: `run.bat` をダブルクリック
   - アプリ（`http://localhost:8501`）が起動します。
3. **外部トンネル公開（ローカルPC運用で4G/5G接続させたい場合）**: `start_tunnel.bat` または `tunnel_launcher.py` を利用します。

## ⚙️ 環境変数設定 (`.env` / Streamlit Secrets)

管理者ログイン用のパスワードは外部に公開されない設定ファイルで管理します。

- **ローカル開発時**: `.env.example` をコピーして `.env` を作成し、`ADMIN_PASSWORD` を設定します（サンプル値: `panda2026`）。
- **Streamlit Cloud 本番時**: 管理画面の「Settings ➔ Secrets」にて `ADMIN_PASSWORD = "任意のパスワード"` を設定します。
