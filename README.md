# パンダロイヤル大会マネージャー 🐼

30人規模のダイスゲーム大会の進行、参加者からのスコア収集、順位・順位点の自動集計、次ラウンドの座席自動抽選をリアルタイムに行うWebアプリケーションです。

---

## 🎯 主な特徴と機能

### 🚩 大会進行フェーズ連動システム（8つのステップ）
運営が管理者ページでフェーズを切り替えることで、参加者がアクセスした際のトップページが自動的に現在のステップに合わせた最適な画面に切り替わります。

1. **エントリーフェーズ**:
   - 参加者の受付登録。スマホからつなげーとIDと名前だけで簡単エントリー。
2. **予選１　準備（席替え表示）**:
   - 予選1の座席発表と席替え案内。「A卓 3番席」のように自分の座席が特大バナーで表示され、スムーズに着席できます。
3. **予選１　結果入力**:
   - 予選1終了後のスコア報告。獲得スコアの入力・送信と同卓メンバーの入力進捗確認。
4. **予選２　準備（席替え表示）**:
   - 予選2の席替え案内。新しい座席が特大表示され、予選1の暫定総合順位も確認できます。
5. **予選２　結果入力**:
   - 予選2終了後のスコア報告。
6. **決勝戦　準備（席替え表示）**:
   - 予選総合順位と運営足切り処理に基づく決勝進出卓の発表。チャンピオン卓・シルバー卓・ブロンズ卓の進出先と座席番号を案内。
7. **決勝戦　結果入力**:
   - 決勝戦終了後のスコア報告。
8. **結果発表（最終スコア表示）**:
   - 表彰式！総合優勝・準優勝・第3位の表彰台カード、シルバー卓覇者、ブロンズ卓覇者、全員分の最終総合スコアランキングが公開されます。

### 📱 参加用QRコード画面（会場プロジェクター・印刷対応）
- アプリ内の「📱 参加用QR」タブを開くだけで、大画面のQRコードが表示されます。
- 会場のプロジェクターで投影したり、運営のタブレット・スマホを見せて参加者にカメラで読み取ってもらうことが可能です。
- QRコード画像をワンクリックでPNG保存（ダウンロード）できるため、印刷して卓上に配布したり、LINEグループに画像共有することもできます。

### ⚙️ 管理者ページ（運営者専用・PC/スマホ両対応）
- パスワード認証で保護された管理画面（初期パスワード: `panda2026`）。
- **進行フェーズ切り替え**: 「進める ➔」「⬅️ 戻す」ボタンやセレクトボックスで、8つのフェーズをワンタップ切り替え。
- **参加者一覧・タグ付け**: 参加者名の横にあるボタン（「運営にする」/「一般に戻す」）をタップするだけで素早くタグ付け。
- **座席自動抽選**: 予選の運営均等配分、および決勝の「運営足切り・繰り上げ昇格」処理をワンクリック実行。
- **QR・URL設定**: Wi-Fi接続時の内部IPアドレスと、外部公開URL（Cloudflare Tunnel 等）の切り替え。
- **リハーサル用テスト機能**: 30名の一括ダミー登録および全ラウンドのスコア自動シミュレーション機能を搭載。

## 🚀 参加者全員がQRコードからアクセスする2つの方法

### 方法1: 4G/5G（モバイル回線）で繋ぐ場合【最もおすすめ・簡単】
参加者が会場のWi-Fiパスワードを入力する手間が一切なく、各自のスマホ回線からアクセスできます。

1. `run.bat` でアプリを起動しておきます。
2. `start_tunnel.bat` をダブルクリックして起動します。
3. 画面上に表示された `https://xxxx.trycloudflare.com` というURLをコピーします。
4. アプリの「⚙️ 管理者ページ」➔「📱 QR・URL設定」タブを開き、URL欄に貼り付けて「保存する」を押します。
5. 「📱 参加用QR」タブを開くと、世界中どこからでも繋がるQRコードが表示されます！

### 方法2: 会場Wi-Fi / テザリング（同一ネットワーク）を使う場合
1. 運営PCと同じWi-Fi（またはスマホのテザリング）に参加者のスマホを接続します。
2. アプリの「📱 参加用QR」タブを開きます。
3. 自動検出されたローカルIP（`http://192.168.x.x:8501`）のQRコードが表示されるので、そのまま読み取ってもらいます。

## 🚀 起動方法

### 簡単起動（Windows環境）
フォルダ内にあるバッチファイルをダブルクリックするだけで自動的に準備と起動が行われます。

1. **初回起動時**: `setup_and_run.bat` をダブルクリック
   - 仮想環境の作成、必要ライブラリの自動インストール、アプリの起動が自動で行われます。
2. **2回目以降の起動**: `run.bat` をダブルクリック
   - ブラウザが自動的に立ち上がり、アプリ画面が表示されます。
3. **外部トンネル起動（必要時）**: `start_tunnel.bat` をダブルクリック

ブラウザのURL: `http://localhost:8501`

## ⚙️ 環境変数設定 (.env)

必要に応じて `.env` ファイル内の設定を変更できます。

```env
ADMIN_PASSWORD=panda2026
```
- `ADMIN_PASSWORD`: 運営スタッフの登録時および運営管理画面へのログイン時に使用するパスワードです。
